자주 묻는 질문

  • 위 사기이력조회 서비스를 이용하거나, 경찰청 사이버범죄수사대(ecrm.police.go.kr)에 신고해 주세요. 채팅 내역과 송금 영수증을 증거로 보관하세요.
  • 낙찰 후 48시간 이내 연락이 없으면 거래 불이행으로 처리되며, 해당 판매자는 서비스 이용이 제한될 수 있습니다. 신고 기능을 통해 접수해 주세요.
  • 마이페이지 → 판매 내역에서 해당 상품을 선택한 후 수정 또는 삭제가 가능합니다.
  • 마이페이지 → 프로필 설정 → 하단 회원탈퇴 버튼을 이용하세요. 탈퇴 시 모든 데이터가 삭제되며 복구가 불가능합니다.
  • 채팅창에서 '안전거래 요청' 버튼을 눌러 에스크로 방식으로 결제하면 구매 확정 전까지 대금이 보호됩니다.
